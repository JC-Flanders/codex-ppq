# 402 Landing Pages Prep

Preparation workspace for one-page landing pages that promote paid endpoints built on x402, L402, and Machine Payments Protocol.

## Files

- [index.html](./index.html) - static landing page implementation.
- [styles.css](./styles.css) - structured design system and responsive page styles.
- [script.js](./script.js) - copy-prompt helper.
- [PRODUCT.md](./PRODUCT.md) - draft product context for future Codex/design passes.
- [DESIGN.md](./DESIGN.md) - draft design baseline for the page series.
- [docs/402-landing-page-research-brief.md](./docs/402-landing-page-research-brief.md) - SEO, IA, protocol, and agent-discovery research.
- [docs/endpoint-page-template.md](./docs/endpoint-page-template.md) - reusable intake checklist and section-by-section page template.
- [docs/payperq-page-redesign-ia-copy.md](./docs/payperq-page-redesign-ia-copy.md) - critique, new IA, and copy draft for the current PayPerQ image-generation page.

## Current Position

The recommended direction is to treat each endpoint page like an API marketplace detail page, not a generic crypto landing page. Lead with the job, price, output, protocol, and trust details. Then provide the machine-readable metadata that agents and discovery systems need.
