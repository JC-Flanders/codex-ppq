How it works

Give the agent access before asking for a task - always.

Your agent sends a keyword, handles the payment challenge, and receives structured JSON it can use in a broader SEO workflow.

  1. 01

    Send a request

    Your AI agent calls the API endpoint with a keyword. No API key, no auth token - just an HTTP request.

  2. 02

    Pay via x402

    The server returns a 402 Payment Required header. Your agent signs a micropayment and retries.

  3. 03

    Get keyword data

    Search volume, difficulty score, intent classification, and related keywords return as structured JSON.

  4. 04

    Act on the result

    Your agent can score the opportunity, draft a brief, or continue researching related keywords.
