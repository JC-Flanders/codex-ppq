## How It Works

### Headline

Give the agent access before asking for a task — always.

### Steps

#### 1. Send a request

Your AI agent calls the API endpoint with a keyword. No API key, no auth token — just an HTTP request.

#### 2. Pay via x402

The server returns a 402 Payment Required header. Your agent signs a micropayment and retries — all in one round trip.

#### 3. Get keyword data

Search volume, difficulty score, intent classification, and related keywords — structured JSON, ready for your agent to act on.
